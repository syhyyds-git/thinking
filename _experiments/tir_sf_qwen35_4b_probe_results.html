Key Findings

Ace-Skill > XSkill by +0.20

Both models score identically within a baseline. Ace-Skill pipeline (experience + better tool orchestration) consistently outperforms XSkill. The advantage is pipeline-level, not model-level.

Qwen3.5-4B is 3-4x more token-expensive

Text-only model needs tool_image_feedback round trips for visual tasks. XSkill 3.5-4B: 361K tokens vs 105K for VL. Ace-Skill 3.5-4B: 248K vs 104K. Higher retry rate too.

Qwen3.5-4B: 25.3% / 11.1% missing usage

SiliconFlow API doesn't always return usage in response headers. Falls back to local estimation (~4 bytes/token). Qwen3-VL-8B has 0% missing usage.

Different samples correct per model

XSkill: VL wins on ocr_337, 4B wins on refcoco_524. Ace-Skill: both models win on instrument_545. No single model dominates all categories. Model diversity may help in ensemble.
